# Fonts for British CV PDF Generation

This directory should contain the following font files:

- `Arial.ttf` - Regular Arial font
- `Arial-Bold.ttf` - Bold Arial font

These fonts are required for the British CV PDF generation feature. Please ensure you have the proper licenses to use these fonts in your application.

You can obtain these fonts from:

1. Your system's font directory (Windows: C:\Windows\Fonts)
2. Microsoft Office installation
3. Adobe Fonts subscription
4. Other legitimate font sources

Note: Make sure you have the proper licenses to use these fonts in your application.
